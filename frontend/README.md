# Utkarsh Portfolio Frontend

React + Vite public portfolio and authenticated skills admin panel.

## Main commands

```powershell
npm.cmd ci
npm.cmd run dev
npm.cmd run build
```

Public site:

```text
http://localhost:5173
```

Admin panel:

```text
http://localhost:5173/admin
```

Use `localhost` for frontend and API. Do not mix it with `127.0.0.1` when testing secure cookies.

See [SETUP.md](../SETUP.md) for complete setup.
